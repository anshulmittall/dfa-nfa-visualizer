      How the simulator decides
      
      
      The simulator keeps a set S of every state the machine could be in. A DFA is the special case where S always holds exactly one state, so the same algorithm runs all three machine types.
      

      S ← ε-closure({ q0 })
for each symbol a in w, left to right:
    T ← ⋃ δ(q, a)   for every q in S
    S ← ε-closure(T)
accept w  if  S ∩ F ≠ ∅
reject w  otherwise

ε-closure(T): T plus every state reachable
from T using only ε-transitions
      
      
      For a DFA or a plain NFA there are no ε-transitions, so ε-closure(T) = T. If S becomes empty, every computation path has died and the string is rejected. Running time is O(|w| · |Q|²) in the worst case.
